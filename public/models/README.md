# Character models

## First-party

Every person in the game is authored for this project in Blender by the pipeline in `scripts/blender-sheriff/`. None of these files is third-party licensed.

- `sheriff.glb` — Sheriff Tom Cassidy: voxel-unioned high-poly sculpt baked to a 41k-triangle low-poly with a 2048² base colour / normal / ORM atlas, 53-bone humanoid rig with fingers, `Idle`/`Walk` clips, 1.86 m to the hat crown.
- `player.glb` and everything in `chars/` (Harlan, Nell and Wade Calder, Dutch Malloy, Ruth Halloran, Amos Pike, Floyd Wicks, Ida Bell, Doc Alvin Frey, Willie Grady, Hattie Reed, Cole Mercer) — generated by the same pipeline from the specs in `scripts/blender-sheriff/chars.py`: each ~30k triangles with its own 2048² atlas, the same 53-bone rig and `Idle`/`Walk` clips.

All of them stand with feet at the origin and face local +Z.

- `horse.glb` — the authored horse, generated by `scripts/blender-horse/` (`hr_build.start()` inside Blender via the MCP): lofted anatomical body unioned by voxel remesh and decimated to ~19k triangles, mane, tail and bridle, with two tack sets on the same 34-bone quadruped rig (`HorseSaddle` for the ridden horse, `HorseHarness` for a team) and `Idle`/`Walk`/`Trot`/`Gallop` clips. Bay coat, points, blaze and sock baked to one 2048² atlas. Hooves on y = 0, barrel centre at the origin, facing local +Z. `src/models/horseModel.js` blends the clips on ground speed.

- `props/western.glb` — the western filler prop kit (barrel, crate, trough, hitch_rail, wheel_lean, wagon_broken, fence_rail, fence_post, skull_longhorn), generated by `scripts/blender-props/` (`pr_build.start()` inside Blender via the MCP). Each prop is a named node built low/high from parts; procedural wood, iron, bone and water shaders on the high mesh bake into one shared 2048² base colour / normal / ORM atlas, so every prop draws with one material. Base on y = 0, long axis +X, front +Z. `src/props.js` places and instances them; `npm run check:western-props` guards names, triangle budgets and placement.

- `props/ranch.glb` — the ranch kit (hay_bale, woodpile, chopping_block, washtub_bench, butter_churn, plow, outhouse, chicken_coop, wagon_farm, hitch_rail_short, grindstone), same pipeline (`pr_build.start("ranch")`, builders in `pr_ranch.py`) with its own shared 2048² atlas and material.

- `props/trail.glb` — the trail and roadside kit (telegraph_pole, mile_marker, signpost, sign_arm, cairn, grave_trail, trunk, campfire_ring), `pr_trail.py`, `pr_build.start("trail")`. Signposts are assembled at runtime (one `sign_arm` per road branch, pivot on the post axis); telegraph wires are generated by `src/props.js` between the insulators at local (±0.5, 6.69, 0.13).

- `props/mine.glb` — the mining kit (headframe, hoist_house, ore_bin, mine_track, mine_car, powder_magazine, water_tank, timber_stack, powder_crates, smokestack, wall_tent, cook_fly, buffer_stop, rail_stack), `pr_mine.py`, `pr_build.start("mine")`. Attachment frames other code relies on (sheave top, rope port, stack top, chute lip, track gauge) are listed in the `pr_mine.py` docstring and mirrored in `src/industry.js`.

- `props/fort.glb` — the fort kit (cannon, cannonballs, flagpole, well, saddle_rack, army_wagon, sentry_box, rifle_crates, rubble_pile), `pr_fort.py`, `pr_build.start("fort")`.

- `props/camp.glb` — the mission and camps kit (horno, carreta, ollas, grave_cross, log_deck, sawbuck, stump, sheep_wagon, wool_sacks, lean_to, shack, picket_line, strongbox, travois, hide_frame, drying_rack, fire_pit), `pr_camp.py`, `pr_build.start("camp")`. The tribal camp pieces are everyday working gear only.

- `props/yard.glb` — the yard kit (windmill_fan, stock_tank, anvil, forge, rowboat, tipi, headstone, headstone_cross, plaza_cross, gatepost_stone, charcoal_pit, log_charred, bench_log, sign_stand, altar), `pr_yard.py`, `pr_build.start("yard")`. `windmill_fan` is the one live piece: hub at its origin, turning about glTF Z, hung by `src/props.js` on the ranch windmill's spinning group (`addMountSpot`) instead of being instanced.

- `props/landmark.glb` — the landmark kit (windmill_tower, lookout_tower, dock_pier, dock_walk, ranch_gate, chimney_ruin, burnt_ruin, cabin_ruin, fishing_shack), `pr_landmark.py`, `pr_build.start("landmark")`. Attachment frames (windmill hub, pier deck tops) are in the `pr_landmark.py` docstring.

- `props/coach.glb` — the Concord stagecoach, `pr_coach.py`, `pr_build.start("coach")`: `coach_body` (rocks on its thoroughbraces), `coach_gear` (running gear, pole hitch, traces and lines to a four-horse team), `wheel_front` and `wheel_rear` at their hubs. Frame numbers are mirrored in `src/models/coachModel.js`; `src/traffic.js` drives it on the stage road.

- `props/furniture.glb` — interior furniture (bed_double, bed_single, cot, chair, stool, pew, table_long, table_square, dresser, wardrobe, cupboard, washstand, desk, gun_rack, cookstove, hearth, bar_counter, bottles, piano, shelf_goods, pulpit, altar_table), `pr_furniture.py`, `pr_build.start("furniture")`. Placed on floors through `addLocalPropSpot` (lot-local frames) by `src/interiors.js`, `src/buildings.js` and `src/landmarks.js`.

## Third-party

`farm-cow.glb` was downloaded from the creator’s Sketchfab download control. Textures are embedded. It is licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); credit the creator and preserve this notice when distributing.

- **Farm Cow Animated Dairy cattle** by **Rukh3D**: https://sketchfab.com/3d-models/farm-cow-animated-dairy-cattle-0e780cb5ab6d457198ded7d4e191a03e

The source file is unchanged. Runtime adaptation changes scale, orientation, material settings and animation behavior for the game. Its SHA-256 checksum and download size are in credits.json. It includes 512-pixel textures and idle/attack/death clips; this is a textured mesh set, not a final high-resolution cattle texture set.

These small self-contained model files live separately from the existing generated terrain texture release bundle. Keep them with the source checkout; Vite copies public/models into the production build.
